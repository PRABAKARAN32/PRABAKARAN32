### 📄 DocForge — Incremental Sync Engine for Documentation RAG

> Keeps documentation RAG knowledge bases fresh — diff, re-embed only what changed.

Most RAG pipelines re-crawl and re-embed everything on every update. For large docs sites (1,000–10,000+ pages), that means long refresh windows and wasted embedding cost. **DocForge** detects exactly which pages changed via content hashing, deletes stale chunks, and re-embeds only new content. A re-sync of an unchanged site does **nothing at all**.
